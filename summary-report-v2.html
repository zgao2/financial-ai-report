产品概述

WindClaw（万得金融终端，Wind Financial Terminal，简称 WFT）是中国金融行业最权威、应用最广泛的金融数据与信息一站式平台。作为机构级金融信息服务的核心终端，Wind 覆盖全球金融市场的数据与信息，为金融机构、政府组织、企业、媒体提供准确、及时、完整的金融数据资讯服务。

万得信息技术股份有限公司成立于 1990 年代，是中国领先的金融数据、信息和软件服务企业。Wind 金融终端经过近 30 年的持续迭代与发展，已成为中国金融机构的标配工具。在中国机构金融信息服务市场占据主导地位，是行业标准的数据供应商。其数据准确性、及时性和完整性被业内广泛认可，成为金融机构投研决策的"黄金标杆"。

目标用户包括：金融机构（银行、证券公司、基金公司、保险公司、信托公司、私募机构）、政府组织（监管机构、政府部门、政策性金融机构）、企业客户（上市公司、大型企业财务与投资部门）、学术机构（高校、研究机构、智库）、媒体（财经媒体、新闻机构）。

核心功能

📈 股票多市场分析
覆盖全球超过 40 个交易所的上市股票数据，包括沪深 A 股、B 股、新三板、科创板、创业板，以及香港、日本、韩国、新加坡、台湾、美国、英国、法国、德国等海外市场。提供基本资料、IPO、再融资、分红、公司公告、盈利预测等数据全覆盖，支持多市场股票对比分析、估值分析、财务分析，以及智能搜索、多维数据浏览、自定义报表功能。
💰 债券全品种覆盖
提供债券市场最完整的数据与服务，覆盖利率债、信用债、资产支持证券、可转债、票据、利率互换、债券指数、中资离岸债等品种。涵盖交易所、银行间、货币中介、做市商全市场数据。提供新闻研报、成交报价、信用监控、最热券、计算器、第三方估值、多曲线分析等功能。Wind 债券数据被业内视为定价基准，其信用债评级违约数据库是风控必备工具。
📊 商品与期货市场
提供国内外 23 家主要商品交易所行情，支持跨期、跨品种、跨市场套利监控。配备 6 种强大分析工具（价差分析、期限结构、库存分析等），及时更新全球大宗商品数据库基本面数据。
💱 外汇市场服务
汇集在岸及离岸人民币即期、掉期、远期实时行情，提供全球重要汇率品种的实时行情、历史走势及交叉汇率信息。覆盖全球经济日历、央行动态、实施滚动资讯、重要外汇新闻。
📋 基金研究平台
提供一站式基金研究平台，覆盖公募、私募、券商资管、银行理财、信托、保险等品种。提供多角度全方位的基金业绩评价、基金比较、基金经理比较、基金公司比较。支持综合屏、智能搜索、多维数据浏览、各类专题统计报表。
📉 指数服务
涵盖中国及全球超过 100 个市场相关指数的行情数据，包含 MSCI、FTSE Russell、S&P 指数等主流指数公司数据。提供成分及权重、回报风险、估值预测、指数比较等指数分析数据，支持用户自定义指数计算。
💼 投资组合管理
提供专业级的组合管理与风险分析平台，支持全品种资产管理（股票、债券、基金、衍生品等）。提供丰富强大的组合监控与分析功能，实时动态监控组合盈亏与风险指标。图表化直观展示，支持绩效归因、风险分解。
📚 宏观经济与行业数据库
Wind 经济数据库（EDB）超过 800 万个经济指标，2 千个分析模板。覆盖 21 个大类行业的价格、产量、进出口等深度行业指标。中国宏观数据核心数据在发布 5 分钟内在数据库更新。覆盖全球超过 200+ 国家和地区经济数据。数据下钻至省、市、区县级别。
📰 新闻与研究报告
实时跟踪 180+ 个财经媒体、200+ 个行业网站，7×24 小时更新。中国近五十家证券或行业研究机构的官方授权研报发布平台。具备国际一流的研报精准触达与合规管理。支持智能搜索、关键词订阅、研报对比分析。
🔌 Excel 插件与 API 接口
强大的 Excel 数据链接功能，方便用户动态获取实时行情、财务数据、宏观行业等数据，构建各种灵活的分析模板和模型。Client API 支持 Python、MATLAB、C++ 等多种编程语言，可轻松获取 Wind 数据，构建数据模型，连接业务流程。适用于量化投资、算法交易、系统对接等场景。
🎥 万得 3C 会议
紧扣财经脉动，聆听前沿观点。每年线上举办上万场分析师路演、业绩发布会、基金路演、论坛峰会和财经直播。与 300 万机构投资者一起交流互动。支持在线提问、互动问答、会议回放。
📱 移动终端
作为金融终端服务的延伸，移动终端同样提供全球金融市场行情、实时快讯、深度资料、研究报告、组合管理、盈利预测等服务。支持全平台运行：Windows、Mac、手机端、Pad 端。随时随地接入 Wind 移动终端，为移动投资决策保驾护航。

产品概述

iFinD Claw（同花顺机构金融数据终端，简称 iFinD）是同花顺公司面向金融机构和专业投资者打造的机构级金融数据与服务终端。作为同花顺"让投资变得更简单"使命的机构级产品延伸，iFinD 致力于为金融机构提供全面、准确、及时的金融数据、资讯和分析工具，支持投研决策、投资管理、风险控制等核心业务场景。

同花顺公司成立于 1995 年，是中国领先的互联网金融信息服务提供商。iFinD 机构终端是同花顺在机构市场的重要布局。2009 年公司在创业板上市（股票代码：300033）。2010 年代推出 iFinD 机构金融数据终端，进军机构市场。2020 年代加强 AI 能力建设，推出智能化投研工具，深化大模型应用。

iFinD 在中国机构金融信息服务市场是 Wind 的主要竞争对手之一，凭借性价比优势、产品创新能力和服务响应速度，在中小机构和个人专业投资者群体中占据一定市场份额。同花顺作为上市公司，财务透明，研发投入持续增加，是机构市场的重要参与者。

核心功能

📈 股票多市场分析
覆盖全球主要市场的股票数据，包括沪深 A 股、B 股、新三板、科创板、创业板、北交所，以及港股、美股、新加坡、日本、韩国等主要市场。提供基本资料、IPO、再融资、分红、公司公告、财务数据全覆盖。支持多市场股票对比分析、估值分析、财务分析。提供智能搜索、F10 深度资料、资金流向分析。特色功能包括龙虎榜、大宗交易、融资融券、股权质押等专题数据。
💰 债券市场服务
提供债券市场数据与服务，覆盖利率债、信用债、可转债、资产支持证券、同业存单等品种。涵盖交易所、银行间市场。提供债券估值、收益率曲线、信用利差分析、债券筛选等功能。相比 Wind，iFinD 在债券数据覆盖深度上略有差距，但在基础数据和常用分析功能上能够满足大部分机构需求。
📋 基金研究平台
提供基金研究与分析功能，覆盖公募基金、私募基金、ETF、LOF 等品种。提供基金业绩评价、基金排名、基金经理分析、基金公司比较。支持基金筛选、基金对比、持仓分析、风格分析。
📚 宏观经济与行业数据库
覆盖中国及全球主要经济体的宏观经济数据，包括 GDP、CPI、PPI、PMI、货币供应、利率、汇率等核心指标。支持数据导出、图表分析、数据对比。行业数据覆盖主要行业的价格、产量、库存、进出口等指标。支持产业链分析、行业对比、趋势分析。宏观和行业数据覆盖广度与 Wind 接近，但在数据颗粒度和历史深度上略有差距。
📰 新闻与研究报告
实时财经新闻 7×24 小时更新，覆盖主流财经媒体。整合多家券商研究所研报，支持智能搜索。提供上市公司公告、监管文件、行业新闻。特色功能包括问财智能搜索、资讯情感分析、热点追踪。
🔢 量化与策略研究
提供量化投资支持工具，包括量化因子库（提供常用量化因子，支持自定义因子）、回测平台（支持策略回测、绩效分析）、API 接口（提供 Python 等编程语言的 API 接口）、策略分享（支持策略分享、社区交流）。
💼 投资组合管理
支持股票、基金等品种的组合管理。提供组合盈亏监控、持仓分析、风险指标计算。支持组合对比、绩效归因。
🔍 问财智能搜索
同花顺自主研发的智能搜索产品，支持自然语言查询，如"市盈率小于 20 的科技股"。基于 AI 的语义理解，快速定位所需数据和信息。
🤖 AI 投顾
基于人工智能的投资顾问服务，提供智能选股、智能诊股、智能仓位建议。7×24 小时在线服务。
📊 Level-2 行情
提供沪深交易所 Level-2 深度行情，包括十档行情、逐笔成交、委托队列等。支持高速刷新，满足交易需求。

💪 优势
