## 一、产品概述

### 1.1 产品定位

FinGenius Claw 是华遥 AI（HuaYao AI）推出的**全球首个 A 股 AI 金融博弈多智能体应用**。不是单一 AI 工具，而是基于多 Agent 博弈架构，模拟真实市场参与者行为的智能投研系统。

### 1.2 目标用户

- **Z 世代投资者**：90 后、00 后年轻投资者
- **专业投资者**：需要快速生成投研报告的从业者
- **量化交易者**：需要 AI 策略支持的量化团队
- **中小私募**：缺乏完整投研团队的小型机构

### 1.3 上线时间与发展历程

- **2023 年**：团队开始研发，扎根 A 股 1700 多天市场观察
- **2024 年**：推翻 100 多个 APP 版本，打磨产品
- **2025 年 7 月**：在 GitHub 开源 AI 金融分析平台
- **2025 年 9 月**：在深圳举办全球发布会，正式发布 FinGenius Claw

### 1.4 市场地位

- **全球首款**A 股 AI 金融博弈多智能体应用
- GitHub 开源项目获得广泛关注
- 00 后共建的 AI 金融生态圈代表产品

## 二、核心功能

### 2.1 多智能体博弈架构

FinGenius Claw 采用独特的**Research-Battle 双子星架构**：

**Research 环境**：
- 多智能体并行处理
- 各专业 AI 分析师同时启动
- 从海量数据源中高效筛选关键信息

**Battle 环境**：
- 模拟真实投研会议
- 智能体之间观点交锋、证据补充、投票表决
- 30 秒内汇总成多模态 PDF 报告
- 传统人工需要 72 小时的工作，AI 只需 30 秒

### 2.2 16 个超级智能体

系统共训练构建了 16 个超级智能体，目前已开源 6 个：

| 智能体 | 功能 |
|--------|------|
| **舆情 Agent** | 监控社交媒体、新闻舆情，计算情绪因子 |
| **游资 Agent** | 追踪游资持仓、龙虎榜数据 |
| **风控 Agent** | 政策风险、估值风险、市场风险分析 |
| **技术分析 Agent** | 均线、MACD、KDJ 等技术指标分析 |
| **筹码分析 Agent** | 股东户数、筹码集中度分析 |
| **大单异动 Agent** | 主力资金流向监控 |

其他 10 个智能体（如"孙子兵法"策略 Agent 等）嵌入在完整 APP 中。

### 2.3 MCP 智能调用

通过**Model Context Protocol（MCP）技术**：
- 实现模型间无缝协作
- 调用专业金融工具和数据源
- 提供更精准的金融数据分析

### 2.4 年轮记忆规则算法

自主研发的记忆系统：
- 不是简单存储记录
- 像树的年轮一样记录用户投资习惯
- 每次对话都能记住"老熟人"
- 避免通用 AI"每次都像初见"的问题

### 2.5 实时数据处理

- 实时获取 A 股行情数据
- 政策变动、规则调整即时解读
- 公告、研报、新闻实时分析

### 2.6 风险预警系统

- 估值风险评估
- 政策风险预警
- 库存周转风险监控
- 综合风险评级（低/中/高）

## 三、技术架构

### 3.1 智能体层次结构

```
BaseAgent（基础智能体）
├── ReActAgent（推理 - 行动智能体）
│   └── ToolCallAgent（工具调用智能体）
│       └── MCPAgent（MCP 协议智能体）
│           ├── SentimentAgent（舆情 Agent）
│           ├── RiskControlAgent（风控 Agent）
│           ├── HotMoneyAgent（游资 Agent）
│           ├── TechnicalAnalysisAgent（技术分析 Agent）
│           └── ReportAgent（报告 Agent）
```

### 3.2 技术栈

- **大语言模型**：支持通义千问、OpenAI 等主流模型
- **搜索引擎**：百度（针对 A 股公告优化）
- **量化平台**：与掘金量化技术合作
- **开发框架**：基于 MCP 协议的智能体框架
- **部署方式**：支持本地部署和云端服务

### 3.3 数据源

- **官方数据**：交易所公告、财报数据
- **舆情数据**：社交媒体、新闻媒体
- **行情数据**：实时股票行情、资金流向
- **研报数据**：机构研究报告
- **量化数据**：技术指标、筹码分布

## 七、缺点与痛点

### 7.1 产品缺点

1. **产品处于早期**
   - 16 个智能体仅开源 6 个
   - 完整功能需要 APP
   - 产品成熟度有待提升

2. **依赖第三方 API**
   - 需要用户自行配置 LLM API
   - 使用成本不稳定
   - 对网络环境有要求

3. **学习成本较高**
   - 需要一定技术基础
   - 配置过程复杂
   - 文档不够完善

4. **数据源局限**
   - 主要聚焦 A 股市场
   - 海外市场覆盖不足
   - 部分数据需要付费

5. **商业模式不清晰**
   - 盈利模式尚在探索
   - 机构版功能不完善
   - 定价策略不透明

6. **品牌认知度低**
   - 相比传统终端知名度低
   - 用户基数小
   - 市场教育成本高

7. **合规风险**
   - AI 生成金融内容合规性待明确
   - 投资建议责任界定模糊
   - 监管政策不确定性

8. **生态建设不足**
   - 插件和扩展功能少
   - 第三方集成有限
   - 社区活跃度待提升

### 7.2 用户痛点

- **配置复杂**：非技术用户难以自行部署
- **成本不确定**：API 调用费用波动大
- **功能不完整**：开源版本功能有限
- **数据依赖**：部分数据源需要额外付费
- **合规担忧**：AI 建议的合规责任不明确
- **品牌信任**：新产品的可靠性存疑
- **学习成本**：需要时间熟悉系统
- **技术支持**：社区支持不够完善
